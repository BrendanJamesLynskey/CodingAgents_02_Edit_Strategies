# CodingAgents 02 — Edit Strategies

A deep-dive into how coding agents actually make changes to source files: search-replace and unified diff wire formats, multi-file atomic edit semantics and rollback, context-window management (load, summarise, forget), the Read/Edit/Write tool trio, a detailed comparison of Aider, Cursor, and Claude Code edit architectures, test-driven agentic edit loops, and failure-recovery strategies when the model produces unparseable or semantically wrong diffs.
